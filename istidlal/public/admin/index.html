كيف تدخل المحرّر

واجهة المحرّر بالإنجليزية (لا ترجمة عربية له بعد)، أما حقول المقالات والصفحات فكلها بالعربية. وهذه أزراره الثلاثة:

Work with Local Repository بلا تسجيل دخول

يحرّر الملفات على جهازك مباشرةً. اضغطه ثم اختر مجلّد المستودع، وستراجع تغييراتك بـgit diff وتدفعها بنفسك. يحتاج Chrome أو Edge.

Sign In Using Access Token يحفظ في GitHub

أنشئ رمزًا شخصيًّا من GitHub بصلاحية repo وألصقه هنا. كل حفظ يصبح كوميت في المستودع مباشرةً — بلا نطاق ولا إعداد إضافي.

Sign In with GitHub يحتاج نطاقًا

الدخول المعتاد بضغطة واحدة. يعمل بعد نشر الموقع على نطاقك وضبط GITHUB_OAUTH_ID وGITHUB_OAUTH_SECRET — الخطوات في docs/EDITOR.md.

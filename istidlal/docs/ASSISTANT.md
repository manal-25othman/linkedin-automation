# المساعد التحريري

مسار خادمي واحد ينتج **مسوّدات فقط**: `POST /api/assistant`.

## لماذا مسوّدات فقط

لا يوجد في هذا المشروع مسار ينشر نصًّا مولَّدًا. المساعد يعيد نصًّا في جسم
الاستجابة، ولا يكتب ملفًّا ولا يفتح كوميتًا ولا يلمس `content/`. النشر يبقى
فعلًا بشريًّا عبر المحرّر (`/admin` أو Pages CMS).

## التشغيل

يحتاج متغيّرين في البيئة — كلاهما خادمي، بلا بادئة `NEXT_PUBLIC_`:

```
ANTHROPIC_API_KEY=sk-ant-…
ASSISTANT_ACCESS_TOKEN=$(openssl rand -base64 32)
ANTHROPIC_MODEL=claude-sonnet-4-5   # اختياري
```

ما لم يُضبطا معًا، يعيد المسار `503` ولا يُستدعى أي مزوّد.

## الاستخدام

```bash
curl -X POST https://YOUR-DOMAIN/api/assistant \
  -H "Authorization: Bearer $ASSISTANT_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "task": "critique",
    "input": "نصّ المسوّدة كاملًا…",
    "sources": ["https://arxiv.org/abs/…"]
  }'
```

المهامّ الثلاث:

| المهمّة | ما تفعله |
| --- | --- |
| `outline` | يقترح هيكل مقال وما يجب قياسه في كل قسم |
| `critique` | يراجع مسوّدة: الادعاء بلا سند، والقسم الناقص، والجملة الترويجية |
| `headlines` | خمسة عناوين بديلة مع سبب كل عنوان |

## الحواجز المطبَّقة

1. **لا اختراع.** تعليمات النظام تمنع اختلاق مصدر أو رابط أو رقم أو اقتباس أو
   اسم دراسة. حيث يلزم مصدر لا يملكه، يكتب `[مصدر مطلوب]`.
2. **الاستشهاد من قائمة مغلقة.** لا يستشهد إلا بالروابط المُمرَّرة في
   `sources`، وتُقبل روابط `https://` فقط، وبحدّ عشرين.
3. **مقاومة الحقن.** نصّك يُغلَّف داخل `<untrusted_input>` ويُعلَن محتوًى
   يُلخَّص لا أمرًا يُطاع؛ وتعليمات النظام تسبقه ولا يستطيع إسقاطها.
4. **إغلاق بالرمز.** المسار محميّ برمز تشغيلي يُقارَن بزمن ثابت، ومحدود بعشرين
   طلبًا في الساعة لكل عنوان.
5. **لا تسريب.** المفتاح لا يُعاد في أي ردّ، وجسم خطأ المزوّد لا يصل المتصفّح.
6. **Markdown لا HTML.** المخرَج نصّ عادي؛ ما يُلصق في المحرّر يمرّ على خطّ
   التصيير نفسه الذي يعقّم مخرجات المقالات.

## الحدّ الذي يجب معرفته

الحواجز أعلاه تقلّل الاختلاق ولا تُلغيه. مخرَج المساعد **مسوّدة تُراجَع**،
ومسؤولية التحقّق من كل رقم ورابط تبقى على المحرّر البشري قبل النشر.

## ملف الأسلوب

صوت الموقع وقواعده في `src/lib/editorial-voice.ts`. تعديله يغيّر سلوك المساعد
في الاستدعاء التالي مباشرةً — لا نسخة ثانية من الأسلوب في مكان آخر.

# هل تحتاج المدونة قاعدة بيانات؟

**لا.** ولا سطرًا واحدًا منها في وضعها الحالي — وهذا قرار معماري مقصود لا نقص.

## لماذا لا

| ما يبدو أنه يحتاج قاعدة | كيف يعمل هنا |
|---|---|
| المقالات والصفحات | ملفات Markdown في المستودع، تُقرأ وقت البناء |
| التصنيفات والوسوم | تُشتقّ من ترويسات الملفات |
| البحث الداخلي | فهرس صغير يُبنى وقت البناء ويعمل في متصفّح الزائر |
| أغلفة المقالات | تُولَّد وقت البناء من التصنيف |
| «الأكثر قراءة» | مقالات الركيزة، تُعلَّم بحقل في الملف |
| التحرير | المحرّر يكتب في المستودع، وGit هو سجلّ النسخ |

النتيجة: صفحات ثابتة تُخدَم من شبكة توصيل، بلا خادم يُستعلَم عند كل زيارة. أسرع، وأرخص (مجاني على الخطط الأساسية)، ولا شيء فيه ينهار عند ازدحام مفاجئ، ولا نسخة احتياطية تُدار — المستودع نفسه هو النسخة.

وكل ما تحتاجه قاعدةٌ عادةً — نسخ، وتاريخ تغييرات، ومراجعة قبل النشر، واسترجاع نسخة قديمة — يعطيه Git أفضل منها لمحتوى نصّي.

## متى تحتاجها فعلًا

| الميزة | تحتاج قاعدة؟ | البديل الموصى به |
|---|---|---|
| نشرة بريدية | **لا** | مزوّد نشرة (Buttondown / MailerLite) يخزّن المشتركين ويرسل ويلغي الاشتراك |
| تعليقات | **لا** | Giscus: تعليقات مبنيّة على GitHub Discussions، مجاني وبلا خادم |
| إحصاءات الزيارات | **لا** | GA4 أو Plausible |
| نموذج تواصل يُحفظ | لا | مزوّد نماذج (Formspree) أو بريد مباشر |
| **حسابات مستخدمين ومحتوى مدفوع** | **نعم** | Supabase أو ما يشبهه |
| **حفظ تفاعلات المستخدمين** (مفضّلة، متابعة) | **نعم** | Supabase |
| **أداة تفاعلية تحفظ بيانات** (حاسبة تحفظ نتائجك) | **نعم** | Supabase أو تخزين خفيف |

يبدو أن سؤالك عن **Supabase** — وهي خيار ممتاز حين تلزم قاعدة. لكن إضافتها الآن تعني: خادمًا يعمل، ومفاتيح تُدار، ونسخًا احتياطية، وسطح هجوم جديد، ومنطقة تخزين تخضع لقوانين خصوصية — مقابل صفر فائدة للمدونة كما هي.

## القاعدة العملية

> أضف قاعدة بيانات يوم يظهر **مستخدم يسجّل الدخول** أو **بيانات يكتبها الزائر وتريد الاحتفاظ بها**. قبل ذلك، كل ما تحتاجه ملفات ومزوّدون متخصّصون.

وإن جاء ذلك اليوم — تعليقات خاصة، أو أدوات تحفظ عمل القارئ، أو محتوى بالاشتراك — فالانتقال سهل: Next.js يدعم Supabase مباشرةً، والمقالات تبقى ملفات كما هي. لا شيء في البناء الحالي يقف في الطريق.

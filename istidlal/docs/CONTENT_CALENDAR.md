## إيقاع أسبوعي

| اليوم | العمل |
|---|---|
| الأحد | بحث الكلمة المفتاحية + مخطط المقال |
| الاثنين–الثلاثاء | الكتابة والكود والقياس |
| الأربعاء | التحرير + الرسوم + `npm run check:content` + قائمة السيو |
| الخميس | النشر + طلب الفهرسة + الروابط الداخلية |
| الجمعة | التوزيع: لينكدإن، إكس، النشرة |
| السبت | القراءة والمتابعة وبناء العلاقات |

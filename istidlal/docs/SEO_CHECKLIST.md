# قائمة تحقق السيو — تُمرَّر على كل مقال قبل النشر

## On-Page

- [ ] العنوان (`title`) ٥٠–٦٠ حرفًا والكلمة المفتاحية في أول ٤٠٪ منه.
- [ ] الوصف (`description`) ١٤٠–١٦٠ حرفًا وفيه وعد + فائدة.
- [ ] `H1` واحد يطابق نيّة البحث لا العنوان حرفيًّا.
- [ ] تدرّج `H2/H3` بلا قفز مستويات.
- [ ] الكلمة المفتاحية في: العنوان، أول ١٠٠ كلمة، عنوان فرعي واحد، الرابط.
- [ ] كلمات دلالية طبيعية (تضمين، متجهات، استرجاع، كمون، هلوسة، تقطيع).
- [ ] ٣–٥ روابط داخلية سياقية + رابط صاعد إلى مقال الركيزة.
- [ ] ٢–٤ روابط خارجية إلى مصادر الطبقة الأولى أو الثانية.
- [ ] فقرات ≤ ٤ أسطر، وجُمل ≤ ٢٥ كلمة.
- [ ] مقتطف مباشر (٤٠–٦٠ كلمة) بعد كل سؤال — استهداف المقتطف المميّز.
- [ ] قسم أسئلة شائعة (يتحوّل تلقائيًّا إلى `FAQPage`).
- [ ] لا تكرار نيّة مع مقال قائم (تفادي أكل الكلمات المفتاحية).

## Technical — مضمون في هذا المشروع

| البند | أين يُنفَّذ | ملاحظة |
|---|---|---|
| `canonical` مطلق | `generateMetadata` في كل صفحة | تحقّق منه بعد أي تغيير مسار |
| بيانات مهيكلة | `src/components/json-ld.tsx` | اختبرها في Rich Results Test |
| خريطة الموقع | `src/app/sitemap.ts` | أضف أي صفحة ثابتة جديدة يدويًّا |
| `robots` | `src/app/robots.ts` | `/search` و`/tags/` محجوبان |
| RSS | `src/app/rss.xml/route.ts` | تُهرَّب النصوص قبل الإدراج |
| صور المشاركة | `src/lib/og.tsx` | تحقّق من صورة كل مقال جديد |
| السرعة | توليد ثابت + خطوط `swap` | راقب LCP < 2.5s · INP < 200ms · CLS < 0.1 |
| RTL | `<html lang="ar" dir="rtl">` | لا تُدخل رسومًا نصّية بالمسافات |

## بعد النشر

- [ ] اطلب الفهرسة في Search Console.
- [ ] أضف روابط داخلية من مقالين قديمين إلى الجديد.
- [ ] انشر على لينكدإن وإكس بصياغة مستقلّة لا نسخة من المقال.
- [ ] بعد ٣٠ يومًا: راجع الظهور والنقر، وحدّث العنوان والوصف إن كان CTR أقلّ من ٢٪.
- [ ] بعد ٩٠ يومًا: أي مقال دون ٥٠ ظهورًا شهريًّا يُحدَّث أو يُدمج، ولا يُترك.

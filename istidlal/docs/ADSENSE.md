# التأهيل لأدسنس — قائمة تحقق تشغيلية

## قبل التقديم

**المحتوى**
- [ ] ٢٥–٣٠ مقالًا أصليًّا، ٨٠٠+ كلمة لكل مقال (المستودع يبدأ بعشرة).
- [ ] عمر النطاق ≥ ٣ أشهر، وحركة عضوية حقيقية مستقرّة ٤ أسابيع.
- [ ] لا محتوى منسوخ أو مترجم آليًّا أو مولّد بلا مراجعة بشرية.

**الصفحات الإلزامية** — كلها منشورة في هذا المشروع:
- [x] `/about` · `/contact` (بريد حقيقي) · `/privacy-policy` · `/terms`
- [x] `/cookie-policy` · `/disclaimer` · `/editorial-policy` · `/advertising-policy`

**سياسة الخصوصية** — تذكر صراحة (منفَّذ في `/privacy-policy`):
- [x] استخدام Google لملفات الارتباط الإعلانية بما فيها `DoubleClick DART`.
- [x] رابط تعطيل الإعلانات المخصّصة `google.com/settings/ads`.
- [x] حقوق GDPR/CCPA وطريقة ممارستها.

**التجربة والتقنية**
- [ ] لافتة موافقة على الكوكيز من مزوّد معتمد لدى Google (إلزامية لزوّار الاتحاد الأوروبي) — **لم تُضف بعد، وهي شرط قبل التقديم**.
- [x] تنقّل واضح: قائمة + تذييل + مسار تنقّل + بحث داخلي.
- [x] صفحة ٤٠٤ مخصّصة، وصفر روابط داخلية مكسورة.
- [x] تصميم متجاوب، ومحتوى الصفحة أكبر بكثير من مساحة الإعلان.
- [ ] HTTPS بلا أخطاء شهادة على النطاق النهائي.

## بعد القبول

1. اضبط `NEXT_PUBLIC_ADSENSE_CLIENT` في البيئة — عندها فقط يُحمَّل سكربت أدسنس.
2. أنشئ الوحدات في لوحة أدسنس ومرّر `slot` لكل `<AdSlot slot="…" />`.
3. ابدأ بوحدتين، وقِس RPM وCore Web Vitals أسبوعين قبل الزيادة.

## قواعد التوزيع الملزِمة

| القاعدة | التنفيذ |
|---|---|
| لا إعلان قبل أول ٣٠٠ كلمة | ضع `AdSlot` بعد الفقرة الثالثة فأكثر |
| حدّ أقصى ٣ وحدات في المتن + ١ بعده | لا تتجاوزه مهما كان طول المقال |
| لا إعلانات في صفحات السياسات والتواصل | لا تُدرج `AdSlot` فيها |
| حجز الأبعاد مسبقًا | `minHeight` في `AdSlot` يمنع انهيار CLS |
| لا نقر ذاتي ولا حثّ على النقر | سبب شائع لإغلاق الحسابات |

## عند الرفض

اقرأ السبب الحرفي في لوحة أدسنس. «محتوى منخفض القيمة» تعني عمقًا لا عددًا: أضف قياسًا أصليًّا وكودًا مجرَّبًا ومراجع أوّلية. انتظر أسبوعين على الأقل، ولا تُعد التقديم بلا تغيير جوهري.

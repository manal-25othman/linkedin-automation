# استدلال — Istidlal

مدونة تقنية عربية متخصصة في **هندسة أنظمة الذكاء الاصطناعي التطبيقية**: الاسترجاع المعزّز (RAG)، الوكلاء، التقييم، اقتصاد الاستدلال، الأمن، والحوكمة.

الخطة التنفيذية الكاملة — من اختيار التخصص إلى التقديم لأدسنس — في [`PLAN.md`](./PLAN.md).

## البنية التقنية

| البند | الاختيار | السبب |
|---|---|---|
| الإطار | Next.js 15 (App Router) | توليد ثابت لكل صفحة = سرعة وCore Web Vitals خضراء |
| التنسيق | Tailwind v4 + متغيّرات CSS | وضعان فاتح/داكن من مصدر لوني واحد |
| المحتوى | ملفات Markdown في `content/articles` و`content/pages` | بلا قاعدة بيانات؛ المقال يُراجَع كما يُراجَع الكود |
| التحرير | لوحة على `‎/admin` تكتب في المستودع عبر GitHub | لا نسخة ثانية من المحتوى ولا خادم إدارة |
| البحث | فهرس مبنيّ وقت البناء يعمل في المتصفّح | بلا خدمة خارجية وبلا إرسال ما يكتبه الزائر |
| الخطوط | Alexandria + Almarai + JetBrains Mono | عناوين هندسية حادّة، متن محايد مريح، كود واضح |
| الخصوصية | لافتة موافقة + Google Consent Mode v2 | لا يُحمَّل سكربت تحليلي أو إعلاني قبل موافقة صريحة |

## التشغيل

```bash
npm install
cp .env.example .env.local     # عدّل القيم
npm run dev                    # http://localhost:3000
```

| الأمر | ماذا يفعل |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج (يولّد كل المقالات وصور المشاركة) |
| `npm start` | تشغيل البناء |

| `npm run typecheck` | فحص الأنواع |
| `npm run check:content` | **فحص المقالات مقابل سياسة التحرير** |
| `npm run prelaunch` | فحص ما قبل الإطلاق: قيم نائبة وإعدادات ناقصة |

## المحرّر

لوحة تحرير على `‎/admin` تعمل على ملفات المستودع مباشرةً: كل حفظ كوميت، وكل كوميت بناء جديد. المقالات تُنشأ وتُعدَّل وتُحذف، والصفحات تُعدَّل فقط.

**Pages CMS (مستضاف، بلا تنصيب):** ادخل [app.pagescms.org](https://app.pagescms.org) بحساب GitHub واختر المستودع — يقرأ `.pages.yml` من جذره ويعرض المقالات والصفحات بحقول عربية.

**المحرّر المدمج، بلا نطاق:** شغّل `npm run dev` وافتح `‎/admin` واختر **Work with Local Repository** (Chrome أو Edge) لتحرير الملفات على قرصك، أو **Sign In Using Access Token** برمز GitHub شخصي لتحفظ كوميتات مباشرة. الدخول بضغطة واحدة (OAuth) يحتاج نطاقًا — الطرق الثلاث في [`docs/EDITOR.md`](./docs/EDITOR.md).

يمكن أيضًا تحرير الملفات مباشرةً كما يلي:

## إضافة مقال

أنشئ `content/articles/<slug-لاتيني>.md`:

```markdown
---
title: "العنوان الظاهر في الصفحة"
seoTitle: "عنوان السيو إن اختلف (اختياري)"
description: "١٢٠–١٧٠ حرفًا: وعد + فائدة."
category: rag            # من src/config/categories.ts
tags: [RAG, التقطيع]
published: 2026-06-02
updated: 2026-08-12      # اختياري
featured: false
takeaways:
  - "نقطة أولى"
  - "نقطة ثانية"
  - "نقطة ثالثة"
---

المتن…
```

القواعد التي يفرضها `npm run check:content` آليًّا:

- رابط لاتيني صغير بشرطات، وعنوان غير مكرّر.
- وصف بين ٨٠ و٢٠٠ حرفًا، وتصنيف معرّف، ووسوم، وتاريخ صحيح.
- ثلاث نقاط خلاصة على الأقل.
- وجود قسم `## المراجع` وقسم `## الأسئلة الشائعة`.
- تحذير إن غاب قسم يحدّد حدود الحلّ («متى لا يصلح…»).

### ملاحظات كتابة

- **المخطّطات**: تُكتب جداول أو قوائم لا رسومًا نصّية بالمسافات — الرسم النصّي العربي يختلّ ترتيبه داخل المتصفّح. لكتلة نصّية عربية بسيطة استخدم السياج ` ```rtl `.
- **الأسئلة الشائعة**: كل `### سؤال` يتحوّل تلقائيًّا إلى بيانات `FAQPage` المهيكلة.
- **العناوين**: تُمنح معرّفات لاتينية (`#s-1`) تلقائيًّا، ويُبنى منها جدول المحتويات.

## ما هو جاهز للسيو

- `metadata` كاملة لكل صفحة مع `canonical` مطلق.
- بيانات مهيكلة: `Organization` · `WebSite` + `SearchAction` · `BlogPosting` · `BreadcrumbList` · `FAQPage` · `Person`.
- `sitemap.xml` و`robots.txt` مولّدان، وتغذية `rss.xml`.
- صور مشاركة (OG) مولَّدة لكل مقال بخط عربي مرفق في المستودع.
- أرشيف الوسوم والبحث الداخلي `noindex, follow`.
- ترويسات أمنية في `next.config.ts`.

## الموافقة على الكوكيز

- الحالة الافتراضية **رفض**: يُضبط Consent Mode v2 على `denied` في `<head>` قبل أي سكربت (`src/lib/consent.ts`).
- لا يُحقَن سكربت Google Analytics ولا AdSense إلا بعد موافقة صريحة على نوعه (`src/components/analytics-scripts.tsx`).
- القرار يُحفظ محليًّا مع تاريخه، ويُعاد سؤال الزائر تلقائيًّا عند رفع `CONSENT_VERSION`.
- رابط «إدارة ملفات الارتباط» في التذييل يعيد فتح اللوحة لتغيير القرار أو سحبه.

## أدسنس

1. لا تفعّل الإعلانات قبل استيفاء قائمة التحقق في [`docs/ADSENSE.md`](./docs/ADSENSE.md).
2. بعد القبول: اضبط `NEXT_PUBLIC_ADSENSE_CLIENT` ومرّر `slot` لمكوّن `AdSlot`.
3. قبل ذلك تظهر المساحات كإطار صامت محجوز الأبعاد — فلا يقفز النص عند التفعيل (حماية CLS).

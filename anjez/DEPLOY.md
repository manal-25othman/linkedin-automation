# نشر أنجز على Vercel — خطوة بخطوة

الوقت المتوقّع: نصف ساعة. لا تحتاجين سجلًا تجاريًّا في هذه المرحلة — الموقع
يعمل بالتحويل البنكي حتى تجهز بوّابة الدفع.

**مهمّ:** المشروع داخل مجلد `anjez/` في المستودع، فاضبطي **Root Directory** على
`anjez` في Vercel وإلا فشل البناء.

---

## ١. قاعدة البيانات (Neon — مجاني)

1. سجّلي في [neon.tech](https://neon.tech) بحساب GitHub.
2. **Create project** → الاسم `anjez` → المنطقة **Frankfurt (eu-central-1)** (الأقرب للسعودية).
3. من صفحة **Connection Details** انسخي رابطين:
   - **Pooled connection** (فيه `-pooler` في العنوان) → سيصير `DATABASE_URL`
   - **Direct connection** (بلا `-pooler`) → سيصير `DIRECT_URL`

> الفرق مهمّ: الترحيلات لا تعمل عبر المجمّع، والتطبيق بلا مجمّع يستنفد حدّ الاتصالات.

## ٢. المشروع على Vercel

1. سجّلي في [vercel.com](https://vercel.com) بحساب GitHub.
2. **Add New → Project** → اختاري مستودع `linkedin-automation`.
3. في شاشة الإعداد:
   - **Root Directory**: اضغطي *Edit* واختاري `anjez`
   - **Framework Preset**: Next.js (يُكتشف تلقائيًّا)
   - **Build Command**: يأتي من `vercel.json` — لا تغيّريها
4. أضيفي متغيّرات البيئة (**Environment Variables**) قبل الضغط على Deploy:

| المتغيّر | القيمة |
|---|---|
| `DATABASE_URL` | رابط Neon المجمّع (pooled) |
| `DIRECT_URL` | رابط Neon المباشر |
| `AUTH_SECRET` | ولّديه بالأمر: `openssl rand -base64 48` |
| `NEXT_PUBLIC_SITE_URL` | `https://اسم-مشروعك.vercel.app` (تعدّلينه بعد ربط النطاق) |
| `PAYMENT_PROVIDER` | `manual` |
| `CRON_SECRET` | أي نصّ عشوائي طويل — Vercel يرسله تلقائيًّا لمهمّة العمولات |
| `SEED_ADMIN_EMAIL` | بريدك |
| `SEED_ADMIN_PASSWORD` | كلمة مرور قويّة (١٠ أحرف فأكثر، فيها حرف ورقم) |

5. **Deploy**. أول بناء يشغّل ترحيلات القاعدة تلقائيًّا (`vercel-build`).

## ٣. تعبئة الكتالوج وحساب الإدارة

الترحيلات تُنشئ الجداول فارغة، والبذور تُشغَّل مرّة واحدة من جهازك:

```bash
cd anjez
# ألصقي روابط Neon نفسها هنا مؤقّتًا
DATABASE_URL="…" DIRECT_URL="…" \
SEED_ADMIN_EMAIL="بريدك" SEED_ADMIN_PASSWORD="كلمة-المرور" \
npm run db:seed
```

> لا تشغّلي `npm run demo:data` على القاعدة الحقيقية — هي طلبات وهمية للتطوير،
> والسكربت يرفض العمل حين `NODE_ENV=production`.

## ٤. بعد أول نشر

1. ادخلي `https://نطاقك/admin/login` بالبريد وكلمة المرور أعلاه.
2. **الإعدادات** → املئي:
   - اسم المستفيد والآيبان واسم البنك (تظهر للعميل في صفحة الطلب)
   - رقم واتساب التواصل (يستقبل إيصالات التحويل)
   - نِسَب العمولة إن أردتِ تغييرها
3. **الخدمات** → راجعي الأسعار والباقات وعدّليها كما تريدين.
4. جرّبي طلبًا حقيقيًّا من صفحة الخدمة حتى صفحة التحويل البنكي.

## ٥. النطاق الخاص

في Vercel: **Settings → Domains → Add** ثم اتبعي تعليمات ربط سجلّات DNS عند
مسجّل النطاق. بعدها حدّثي `NEXT_PUBLIC_SITE_URL` إلى نطاقك الجديد — روابط
إحالة المسوّقين تُبنى منه.

## ٦. لاحقًا: تفعيل الدفع الإلكتروني

عند جاهزية السجل التجاري وحساب ميسر:

1. غيّري `PAYMENT_PROVIDER` إلى `moyasar`.
2. أضيفي `MOYASAR_SECRET_KEY` و `MOYASAR_PUBLISHABLE_KEY`.
3. أضيفي `MOYASAR_WEBHOOK_SECRET` بقيمة من اختيارك، واضبطي في لوحة ميسر
   Webhook على `https://نطاقك/api/payments/webhook` بنفس القيمة.
4. أعيدي النشر (Redeploy).

## مشاكل شائعة

| العَرَض | السبب والحلّ |
|---|---|
| فشل البناء: `Cannot find module` | Root Directory ليس `anjez` |
| فشل البناء عند الترحيلات | `DIRECT_URL` يشير إلى المجمّع — استخدمي الرابط المباشر |
| الموقع يفتح والكتالوج فارغ | لم تُشغَّل البذور (الخطوة ٣) |
| `AUTH_SECRET` error | المتغيّر مفقود أو أقصر من ٢٤ حرفًا |
| العمولات تبقى «معلّقة» بعد اكتمال الطلب | طبيعي: تُعتمد بعد مدّة التثبيت (١٤ يومًا افتراضيًّا) |

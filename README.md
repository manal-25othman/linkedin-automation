# linkedin-automation

أتمتة نشر يومي على لينكدإن باستخدام **n8n** فقط — بدون أي أكواد أو سكربتات خارجية.

يقرأ الـ workflow نصوص البوستات من Google Sheet، ينشر بوستاً واحداً كل يوم الساعة 9 صباحاً على حسابك الشخصي في لينكدإن، ثم يحدّث حالة الصف إلى `Posted` حتى لا يتكرر نشره.

```
Schedule Trigger (9 صباحاً)
        ↓
Google Sheets — قراءة الصفوف ذات الحالة Pending
        ↓
Limit — أخذ صف واحد فقط
        ↓
IF — التحقق أن نص البوست غير فارغ
        ↓
LinkedIn — نشر البوست (Person / OAuth2)
        ↓
Google Sheets — تحديث الحالة إلى Posted
```

## المتطلبات قبل البدء

قبل أن تبدأ، تأكد أن لديك:

1. **حساب n8n** (سحابي أو مُستضاف ذاتياً) — الخطوة 1.
2. **حساب Google** لإنشاء الشيت وربطه — الخطوتان 2 و 3.
3. **حساب لينكدإن عادي + صفحة (LinkedIn Page)** — لينكدإن **لا يسمح** بإنشاء تطبيق مطوّر بدون ربطه بصفحة. إذا لم تكن تملك واحدة، أنشئ صفحة مجانية من [linkedin.com/company/setup/new](https://www.linkedin.com/company/setup/new/) قبل الخطوة 4.

   **لا تحتاج LinkedIn Premium.** كل ما في هذا الدليل — Developer Portal، ومنتج Share on LinkedIn، وصلاحية `w_member_social` — مجاني ومتاح لأي حساب عادي، ولن تُطلب منك وسيلة دفع في أي خطوة.

   **الصفحة ليست حساباً ثانياً.** تُنشأ من داخل حسابك الحالي: بلا بريد جديد، ولا كلمة مرور جديدة، ولا تسجيل دخول منفصل — تصل إليها من قائمة "إدارة الصفحات" في نفس حسابك، تماماً كصفحة فيسبوك تُدار من حسابك الشخصي. وإن كنت **أدمن على أي صفحة موجودة مسبقاً** (صفحة جهة عملك مثلاً) فاستخدمها ولا تنشئ جديدة — تحقق من [قائمة صفحاتك](https://www.linkedin.com/mypreferences/d/manage-pages).

   **ولا تحتاج شركة مسجّلة.** الصفحة مجانية ويمكن إنشاؤها لعلامتك الشخصية أو لمشروع جانبي أو لعملك الحر. ربط التطبيق بصفحة إجراء إداري من لينكدإن لمكافحة التطبيقات العشوائية، لا تحقق من كيان تجاري. النشر سيبقى على حسابك الشخصي، وقد لا تنشر في الصفحة شيئاً أبداً.

   ما قد يعيقك فعلاً هو شروط إنشاء الصفحة نفسها: لينكدإن يشترط أن يكون ملفك الشخصي مضى على إنشائه فترة (أسبوع تقريباً)، ومكتملاً نسبياً (صورة ومسمى وظيفي وخبرة)، وله عدد معقول من الاتصالات — وقد يطلب في بعض الحالات بريداً بنطاق خاص بدل Gmail. إن ظهرت رسالة منع عند إنشاء الصفحة فالسبب أحد هذه الشروط.

   **إن تعذّر إنشاء صفحة نهائياً:** لا يوجد التفاف على هذا عبر الواجهة الرسمية — الربط بصفحة إلزامي. البديل حينها أداة جدولة وسيطة معتمدة لدى لينكدإن (Buffer أو Publer مثلاً) تُصرّح لها مباشرة بلا تطبيق مطوّر، ويستدعيها n8n عبر واجهتها — لكنها تضيف طرفاً ثالثاً واشتراكاً غالباً.

## الخطوة 1: تجهيز n8n

### الخيار (أ): n8n Cloud — الأسهل والموصى به

1. ادخل إلى [n8n.io](https://n8n.io) واضغط **Get started / Sign up**.
2. سجّل بالبريد الإلكتروني وفعّل الحساب من رسالة التفعيل.
3. اختر اسماً للـ workspace، وستحصل على رابط خاص بك بالشكل:
   `https://<اسم-حسابك>.app.n8n.cloud`
4. **احفظ هذا الرابط** — ستحتاجه لبناء روابط الـ OAuth Redirect في الخطوتين 2 و 4.

> التجربة المجانية محدودة المدة. بعدها تحتاج اشتراكاً مدفوعاً، أو انتقل إلى الخيار (ب).

### الخيار (ب): تشغيل n8n محلياً على جهازك

مناسب للتجربة فقط — الجدولة اليومية لن تعمل إلا وجهازك يعمل و n8n مفتوح.

بـ Docker:

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e GENERIC_TIMEZONE="Asia/Riyadh" \
  -e TZ="Asia/Riyadh" \
  docker.n8n.io/n8nio/n8n
```

ثم افتح `http://localhost:5678`.

> **تنبيه مهم:** روابط الـ OAuth لا تعمل مع `localhost` مع لينكدإن لأنه يشترط رابطاً بـ HTTPS. للتجربة المحلية استخدم نفقاً مثل [ngrok](https://ngrok.com) واستعمل الرابط الناتج (`https://xxxx.ngrok-free.app`) بدل `localhost`.

### الخيار (ج): استضافة على VPS — الأنسب للتشغيل الدائم

على خادم فيه Docker ونطاق موجّه إليه:

```bash
docker volume create n8n_data

docker run -d --restart unless-stopped \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e N8N_HOST="n8n.example.com" \
  -e N8N_PROTOCOL="https" \
  -e WEBHOOK_URL="https://n8n.example.com/" \
  -e GENERIC_TIMEZONE="Asia/Riyadh" \
  -e TZ="Asia/Riyadh" \
  -e N8N_ENCRYPTION_KEY="ضع-مفتاحاً-عشوائياً-طويلاً-هنا" \
  docker.n8n.io/n8nio/n8n
```

ضع أمامه Nginx أو Caddy مع شهادة SSL (Let's Encrypt) حتى يصبح الوصول عبر `https://n8n.example.com`. وجود HTTPS **شرط إلزامي** لعمل OAuth مع لينكدإن.

> احتفظ بنسخة من `N8N_ENCRYPTION_KEY` في مكان آمن — بدونه لن تستطيع فك تشفير بيانات الاعتماد المحفوظة إذا أعدت بناء الحاوية.

## الخطوة 2: إنشاء Google Sheet وربطه بـ n8n

### 2.1 إنشاء الشيت

1. أنشئ جدولاً جديداً على [sheets.google.com](https://sheets.google.com).
2. غيّر اسم التبويب السفلي إلى **`Posts`** بالضبط (حساس لحالة الأحرف).
3. استورد النموذج: **File → Import → Upload** واختر `templates/google-sheet-template.csv`، ثم اختر *Replace current sheet*.
   - أو اكتب الرؤوس يدوياً في الصف الأول: `Date` و `PostText` و `Status`.
4. انسخ **معرّف الشيت** من الرابط — الجزء الذي بين `/d/` و `/edit`:

   ```
   https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890/edit
                                          └────────── هذا هو المعرّف ──────────┘
   ```

### 2.2 معنى الأعمدة

| العمود | المعنى | ملاحظات |
|---|---|---|
| `Date` | التاريخ المخطط للنشر | للتنظيم والمراجعة فقط — الـ workflow لا يعتمد عليه في الترتيب |
| `PostText` | نص البوست كاملاً | هذا ما يُنشر حرفياً على لينكدإن |
| `Status` | حالة الصف | `Pending` = بانتظار النشر، `Posted` = تم نشره |

**أسماء الأعمدة بالإنجليزية إلزامية** لأن الـ workflow يشير إليها في التعبيرات (`$json.PostText`) وفي فلتر البحث. المحتوى نفسه بالعربية بلا مشكلة.

> لإضافة سطر جديد داخل نص البوست: اضغط **Alt + Enter** داخل الخلية.

### 2.3 ربط Google بـ n8n

1. ادخل [Google Cloud Console](https://console.cloud.google.com) وأنشئ مشروعاً جديداً.
2. من **APIs & Services → Library** فعّل الاثنين معاً:
   - **Google Sheets API**
   - **Google Drive API** (مطلوب لتصفح الملفات من داخل n8n)
3. من **APIs & Services → OAuth consent screen**: اختر **External**، املأ اسم التطبيق وبريدك، واحفظ.
4. في قسم **Test users** أضف بريدك الإلكتروني نفسه. بدون هذه الخطوة سترى خطأ `access_denied` عند الربط.
5. من **Credentials → Create Credentials → OAuth client ID**:
   - النوع: **Web application**
   - في **Authorized redirect URIs** ضع رابط n8n بالشكل:
     ```
     https://<رابط-n8n-الخاص-بك>/rest/oauth2-credential/callback
     ```
   - انسخ **Client ID** و **Client Secret**.
6. في n8n: **Credentials → Add credential → Google Sheets OAuth2 API**.
   - الصق الـ Client ID و Client Secret.
   - **قارن رابط الـ Redirect URL الظاهر في n8n** بما وضعته في جوجل — يجب أن يتطابقا حرفاً بحرف.
   - اضغط **Sign in with Google** وأكمل الموافقة.
   - إذا ظهرت شاشة "Google hasn't verified this app" اضغط **Advanced → Go to ... (unsafe)** — طبيعي في التطبيقات تحت الاختبار.
7. احفظ باسم واضح مثل `Google Sheets - LinkedIn Automation`.

## الخطوة 3: تسجيل تطبيق على LinkedIn Developer Portal

### 3.1 إنشاء التطبيق

1. ادخل [linkedin.com/developers/apps](https://www.linkedin.com/developers/apps) واضغط **Create app**.
2. املأ الحقول:
   - **App name**: مثلاً `n8n Daily Poster`
   - **LinkedIn Page**: اربطه بصفحة الشركة التي تملكها (انظر قسم المتطلبات).
   - **App logo**: ارفع أي صورة.
   - وافق على شروط الاستخدام.
3. بعد الإنشاء، افتح تبويب **Settings** واضغط **Verify** بجانب الصفحة. سيولّد رابط تحقق — افتحه من حساب يملك صلاحية الأدمن على الصفحة وأكّد. **التطبيق لن يعمل قبل إتمام هذا التحقق.**

### 3.2 تفعيل المنتجات (Products)

من تبويب **Products** اطلب المنتجين:

| المنتج | لماذا |
|---|---|
| **Share on LinkedIn** | يمنح صلاحية `w_member_social` — وهي صلاحية النشر نفسها |
| **Sign In with LinkedIn using OpenID Connect** | يمنح `openid` و `profile` — يحتاجها n8n لمعرفة هويتك وجلب الـ Person ID |

كلاهما يُفعّل ذاتياً خلال دقائق. حدّث الصفحة حتى تنتقل من *Requested* إلى **Added**.

> **لا تطلب** منتج *Community Management API* لهذا الاستخدام — فهو للنشر باسم صفحة شركة ويحتاج مراجعة يدوية من لينكدإن.

### 3.3 ضبط الـ Auth وربطه بـ n8n

1. في n8n: **Credentials → Add credential → LinkedIn OAuth2 API**.
2. انسخ **OAuth Redirect URL** الظاهر أمامك في n8n، وشكله:
   ```
   https://<رابط-n8n-الخاص-بك>/rest/oauth2-credential/callback
   ```
3. ارجع إلى تطبيق لينكدإن → تبويب **Auth** → في **Authorized redirect URLs for your app** اضغط **Add redirect URL** والصق الرابط، ثم **Update**.
4. من نفس التبويب انسخ **Client ID** و **Primary Client Secret**.
5. الصقهما في n8n.
6. تحقق أن حقل الـ **Scope** في n8n يحتوي على `w_member_social` (إضافةً إلى `openid` و `profile`). إن كان ناقصاً أضفه يدوياً.
7. اضغط **Connect my account**، وافق على الأذونات، ويجب أن تظهر علامة **Account connected**.
8. احفظ باسم واضح مثل `LinkedIn - Personal Account`.

## الخطوة 4: استيراد الـ workflow وتفعيله

### 4.1 الاستيراد

1. حمّل ملف `workflows/linkedin-daily-post.json` من هذا المستودع.
2. في n8n: **Workflows → Add workflow → القائمة (⋯) أعلى اليمين → Import from File**.
3. اختر الملف. ستظهر أمامك العقد الست وملاحظة الإعداد الصفراء.

### 4.2 القيم التي يجب استبدالها

الملف يحتوي على قيم مؤقتة **لن يعمل قبل تغييرها**:

| العقدة | القيمة المؤقتة | ما تضعه مكانها |
|---|---|---|
| `Get Pending Posts` | `YOUR_GOOGLE_SHEET_ID` | معرّف الشيت من الخطوة 2.1 |
| `Get Pending Posts` | — | اختر بيانات اعتماد Google Sheets |
| `Mark as Posted` | `YOUR_GOOGLE_SHEET_ID` | نفس معرّف الشيت |
| `Mark as Posted` | — | نفس بيانات اعتماد Google Sheets |
| `Publish to LinkedIn` | `YOUR_LINKEDIN_PERSON_ID` | اختر بيانات اعتماد لينكدإن أولاً، ثم **اختر اسمك من القائمة المنسدلة في حقل Person** — ستُملأ القيمة تلقائياً |

> في حقل الـ Person: بعد ربط بيانات الاعتماد، افتح القائمة المنسدلة واختر اسمك. لا تكتب القيمة يدوياً.

### 4.3 ضبط التوقيت

الملف مضبوط افتراضياً على **Asia/Riyadh**. لتغييره: **Workflow menu (⋯) → Settings → Timezone**. الساعة 9 صباحاً تُحسب حسب هذا الإعداد.

### 4.4 الاختبار قبل التفعيل

1. تأكد أن في الشيت صفاً واحداً على الأقل حالته `Pending`.
2. اضغط **Execute workflow** لتشغيل تجريبي يدوي.
3. راقب العقد — يجب أن تتحول كلها إلى اللون الأخضر.
4. تحقق من نتيجتين:
   - البوست ظهر فعلاً على صفحتك في لينكدإن.
   - عمود `Status` في ذلك الصف تحوّل إلى `Posted`.

### 4.5 التفعيل

بعد نجاح الاختبار، فعّل المفتاح **Active** أعلى يمين الشاشة. من الآن سيعمل تلقائياً كل يوم 9 صباحاً.

> على n8n المُستضاف ذاتياً، الجدولة تعمل فقط ما دامت الحاوية شغّالة. تأكد من `--restart unless-stopped`.

## كيف تضيف بوستات جديدة

أضف صفاً جديداً في الشيت واملأ `PostText` واكتب `Pending` في عمود `Status`. الـ workflow يلتقطه في أقرب تشغيل. الصفوف التي حالتها `Posted` يتجاهلها تماماً.

الـ workflow ينشر **بوستاً واحداً في كل تشغيل** (عبر عقدة `Take One Post`)، ويأخذ أول صف `Pending` بترتيب الشيت. رتّب صفوفك بالترتيب الذي تريد النشر به.

## حل المشاكل الشائعة

| المشكلة | السبب والحل |
|---|---|
| `403 Forbidden` من عقدة لينكدإن | صلاحية `w_member_social` غير مفعّلة. تأكد أن منتج **Share on LinkedIn** حالته *Added*، ثم أعد الربط من زر **Connect my account** لتوليد توكن جديد بالصلاحية الصحيحة |
| `invalid_redirect_uri` | الرابط في تبويب Auth لا يطابق الظاهر في n8n. قارنهما حرفاً بحرف — الفروقات الشائعة: `http` بدل `https`، أو `/` زائدة في النهاية |
| توقف النشر فجأة بعد شهرين | توكن لينكدإن للأعضاء صالح **60 يوماً** فقط. افتح بيانات الاعتماد في n8n واضغط **Connect my account** مجدداً. ضع تذكيراً دورياً كل شهرين |
| الـ workflow يعمل لكن لا ينشر شيئاً | لا يوجد صف حالته `Pending`، أو اسم التبويب ليس `Posts`، أو أسماء الأعمدة غير مطابقة تماماً |
| `Status` لا يتحدث بعد النشر | عقدة `Mark as Posted` تطابق على `row_number`. تأكد أنك لم تغيّر اسم عقدة `Take One Post` — التعبير يشير إليها بالاسم |
| خطأ `access_denied` من جوجل | بريدك غير مضاف في **Test users** داخل OAuth consent screen |
| العقد لا تجد أعمدة الشيت | اضغط أيقونة التحديث بجانب قائمة الأعمدة داخل العقدة لإعادة قراءة بنية الشيت |

## ملاحظات مهمة

- **النشر يتم عبر واجهة لينكدإن الرسمية** (Share on LinkedIn API) وليس عبر محاكاة متصفح أو scraping. هذا يعني أنه متوافق مع شروط استخدام لينكدإن ولا يعرّض حسابك للتقييد.
- **توكن الوصول ينتهي كل 60 يوماً** لحسابات الأعضاء. هذه سياسة من لينكدإن نفسه ولا يمكن تجاوزها في هذا النوع من التطبيقات — يلزم إعادة ربط دورية.
- **جودة المحتوى مسؤوليتك.** النشر الآلي لمحتوى متكرر أو منخفض القيمة يضر بمصداقيتك أكثر مما ينفع، حتى لو كان تقنياً سليماً. استخدم الشيت للجدولة والتنظيم، لا لتعبئة فراغ.
- لا يوجد في هذا المستودع أي كود Python أو سكربتات خارجية — كل المنطق داخل عقد n8n الرسمية.

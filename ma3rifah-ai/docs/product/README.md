## أربعة أشياء يجب أن تُقرأ قبل أي شيء آخر

1. ~~**الهامش سالب**~~ → **عولج.** صار ٩٠–٩٣٪ بتغيير النموذج وإعادة التسعير،
   وثُبِّت كاختبار آلي يفشل البناء إن عاد سالبًا ([٠١ §٧](./01-AUDIT.md) ·
   [٠٤](./04-PRICING-STRATEGY.md))
2. **«مبنيّة للعربية» لم تعد فارقًا** — Notion صارت عربية في يناير ٢٠٢٦ ([٠٢](./02-COMPETITIVE-ANALYSIS.md))
3. **منافسون سعوديون موجودون** — مستند، AiBot، AIP ([٠٢](./02-COMPETITIVE-ANALYSIS.md))
4. **لم يدفع أحد بعد** — القيد الباقي توزيع لا بناء ([٠٩ §٦](./09-PROJECT-DOC.md))

# التموضع والجمهور المستهدف — معرفة AI

> نسخة ١٫٠ · أغسطس ٢٠٢٦

---

## ١) جملة التموضع

> **لـ**الشركات السعودية الخدمية التي تعيش على اللوائح والإجراءات
> **التي** يضيع وقت خبرائها في تكرار إجابات مكتوبة أصلًا
> **معرفة AI** مساعد معرفة يجيب من مستنداتكم بالعربية مع ذكر المصدر
> **الذي** — بخلاف Notion وCopilot وأدوات البحث المؤسسي —
> **يتحقّق من كل رقم قبل عرضه، ويكشف لكم ما لا يجيب عنه توثيقكم.**

**اختبار الجملة:** أي منافس يستطيع قول أول ثلاثة أسطر. **لا أحد يستطيع قول
السطر الأخير.** ولذلك هو التموضع.

## ٢) تحوّل الرسالة

| من (اليوم) | إلى (المقترح) | السبب |
|---|---|---|
| «مبنيّة للعربية أولًا» | «كل رقم يُقارن بالمستند قبل أن يصلك» | Notion صارت عربية مجانًا في يناير ٢٠٢٦ |
| «إجابات موثّقة بالمصدر» | «إجابة تستطيع مراجعتها في ثلاثين ثانية» | الأولى ادّعاء، الثانية فعل يقيسه العميل |
| «منصة ذكاء معرفي» | «مساعد اللوائح والإجراءات» | «ذكاء معرفي» لا يعني شيئًا لمدير موارد بشرية |
| «فجوات المعرفة» | «تقرير: ما لا يجيب عنه توثيقكم» | المصطلح للمنتج، والوصف للعميل |

## ٣) الجمهور — ثلاث طبقات

### 🎯 الطبقة الأولى (ابدئي هنا)

**شركات خدمية سعودية، ٥٠–٣٠٠ موظفًا، كثيفة الإجراءات.**

القطاعات بالترتيب:
1. **مكاتب المحاماة والاستشارات النظامية** — تعيش على النصوص، وتقدّر المصدر والصفحة أكثر من أي قطاع
2. **إدارات الموارد البشرية وشركات التوظيف** — أكثر من يعاني تكرار السؤال
3. **المقاولات والهندسة** — اشتراطات فنية وسلامة، والخطأ فيها مكلف
4. **الشركات المالية وفرق الامتثال** — الامتثال يفرض التوثيق أصلًا

**لماذا هؤلاء أولًا:** الألم واضح ومتكرر، والقرار عند شخص واحد أو اثنين،
والميزانية موجودة، ومستنداتهم مكتوبة فعلًا (لا تحتاجين إقناعهم بالتوثيق قبل
البيع).

### 🔸 الطبقة الثانية (بعد ٥ عملاء)

- المجمّعات الطبية والمستشفيات الخاصة (دورة بيع أطول، امتثال أشدّ)
- التعليم الخاص (جامعات ومدارس أهلية)
- الجهات شبه الحكومية (دورة طويلة جدًا، لكن العقد كبير ومستقر)

### 🔹 الطبقة الثالثة (بعد إثبات السوق)

- الخليج: الإمارات، قطر، الكويت (تحتاج الإنجليزية والتوطين)
- المؤسسات الكبيرة ١٠٠٠+ موظفًا (تحتاج SLA واستضافة خاصة وSSO)

### ⛔ من لا تستهدفينهم الآن — وهذا قرار لا إغفال

| الفئة | لماذا لا |
|---|---|
| الشركات التقنية | ستبني الحل بنفسها أو تشغّل Onyx مجانًا. أصعب بيع وأقل ولاء |
| الشركات دون ٢٠ موظفًا | الألم غير كافٍ — يسألون المدير مباشرة |
| من لا توثيق لديه | ستبيعين مشروع توثيق لا اشتراكًا. دورة طويلة وقيمة متأخرة |
| الجهات الحكومية | مشتريات معقّدة تحتاج تأهيلًا ومرجعية. أجّليها |
| خارج الخليج | لا ميزة PDPL ولا ميزة اللغة تكفي وحدها |

## ٤) شخصيات العملاء

### 👤 الشخصية ١ — نورة · مديرة الموارد البشرية · 🏆 **الأهم**

| | |
|---|---|
| المنصب | مدير/ة موارد بشرية أو شؤون موظفين |
| القطاع | خدمي · ٨٠–٢٥٠ موظفًا |
| الألم | تشرح السياسة نفسها كل أسبوع؛ الموظف الجديد يستهلك أسابيع؛ والإجابة تختلف باختلاف من سُئل |
| الهدف | تقليل الأسئلة المتكررة، وتوحيد الإجابة، وتسريع الإلحاق |
| دافع الشراء | استرجاع وقتها هي — لا «التحوّل الرقمي» |
| الاعتراضات | «هل يعطي إجابة خاطئة؟» · «هل يرى الموظف رواتب غيره؟» · «كم يأخذ مني إعداده؟» |
| موقعها | **المستفيد والمؤثّر** — نادرًا صاحبة القرار المالي |
| حساسية السعر | متوسطة — تقارنه براتب متدرّب |
| قناتها | لينكدإن، مجموعات واتساب مهنية، توصية زميلة |
| **رسالتها** | «أجيبي مرة واحدة — والنظام يجيب بعدك» |

### 👤 الشخصية ٢ — فهد · المدير التنفيذي / المالك · 💰 **صاحب القرار**

| | |
|---|---|
| المنصب | رئيس تنفيذي أو مالك · ٥٠–٣٠٠ موظفًا |
| الألم | المعرفة في رؤوس الأفراد؛ استقالة خبير تكشف أن نصف الإجراءات لم تُكتب |
| الهدف | استمرارية العمل، وتقليل الاعتماد على أشخاص |
| دافع الشراء | تقليل المخاطر — لا الكفاءة |
| الاعتراضات | «كم يكلّف؟» · «هل تخرج بياناتنا؟» · «هل يستعمله الموظفون فعلًا؟» |
| موقعه | **صاحب القرار** |
| حساسية السعر | عالية على المبلغ المطلق، منخفضة إن ربط بمخاطرة |
| قناته | توصية، لينكدإن، فعاليات |
| **رسالته** | «حين يستقيل خبيركم، تبقى معرفته» |

### 👤 الشخصية ٣ — عبدالله · مدير التقنية / أمن المعلومات · 🛡️ **حارس البوابة**

| | |
|---|---|
| الألم | مسؤول عن تسريب لم يقرّره؛ الموظفون يستعملون ChatGPT بلا رقابة |
| الهدف | إثبات الامتثال — PDPL وNDMO والضوابط الوطنية |
| دافع الشراء | إغلاق مخاطرة مفتوحة |
| الاعتراضات | «أين تُخزَّن؟» · «هل تُستعمل للتدريب؟» · «كيف يُفرض العزل؟» · «هل من سجل تدقيق؟» |
| موقعه | **لا يشتري لكنه يستطيع الرفض** — وهو الأهم أن يُقنَع |
| **رسالته** | «العزل مفروض في قاعدة البيانات ومُثبَت بـ١١٤ اختبارًا — إليك التقرير» |

### 👤 الشخصية ٤ — سارة · مديرة الامتثال · ⚖️ (قطاع مالي وطبي)

| | |
|---|---|
| الألم | تحتاج إثبات أن الموظف اطّلع على الإجراء الصحيح والنسخة الأحدث |
| دافع الشراء | جاهزية التدقيق |
| موقعها | **مؤثّرة قوية ومحفّزة على الميزانية** |
| **رسالتها** | «كل إجابة تحمل مصدرها وصفحتها — والمؤرشف لا يُجاب منه» |

## ٥) رحلة الشراء والرسالة عند كل مرحلة

| المرحلة | من | ما يحتاجه | الرسالة | نداء الفعل |
|---|---|---|---|---|
| الوعي | نورة | يدرك أن للمشكلة اسمًا | «السؤال نفسه كل أسبوع» | استكشفي المنصة |
| الاهتمام | نورة | يرى المنتج | صور شاشة + عرض حيّ | جرّبيها على مستند واحد |
| التقييم | فهد | مقارنة وتكلفة | «مقابل ربع راتب متدرّب» | احجز عرضًا |
| التحقق الأمني | عبدالله | إثبات لا وعد | تقرير العزل | حمّل ملخّص الأمان |
| الشراء | فهد | تسعير واضح | خطط بالريال بلا رسوم تأسيس | ابدأ الاشتراك |
| التبنّي | نورة | نتيجة سريعة | رحلة تفعيل موجَّهة | ارفعي أول مستند |
| التوسّع | فهد | دليل قيمة | تقرير شهري بالاستعمال والفجوات المسدودة | أضف قسمًا جديدًا |

## ٦) استراتيجية نداءات الفعل (CTA)

**المشكلة الحالية:** «ابدأ مجانًا» في كل موضع. وهو نداء لا يناسب فهد ولا
عبدالله — والمشتري المؤسسي لا يبدأ بتسجيل ذاتي.

**المقترح:**

| الموضع | النداء الأساسي | النداء الثانوي | الهدف |
|---|---|---|---|
| صدر الرئيسية | جرّبها على مستنداتك | شاهد عرضًا (٩٠ ثانية) | تسجيل / مشاهدة |
| بعد قسم المشكلة | كيف تعمل؟ | — | تعميق |
| بعد قسم الأمان | حمّل ملخّص الأمان (PDF) | — | **التقاط بريد عبدالله** |
| صفحة الأسعار | ابدأ التجربة | تحدّث إلى المبيعات | تحويل / فرصة بيع |
| صفحة القطاع | احجز عرضًا لقطاعك | — | فرصة مؤهَّلة |
| نهاية كل صفحة | ابدأ التجربة | احجز عرضًا | مساران متوازيان |
| داخل اللوحة (تجربة) | أكملي تجهيز مساحتك | ادعُ فريقك | تفعيل |

**قاعدة:** كل صفحة تحمل **مسارين**: تسجيل ذاتي لمن يريد التجربة، وحجز عرض
لمن يريد التحدث. الاكتفاء بواحد يفقد نصف الجمهور.

## ٧) رسائل الثقة بلغة غير تقنية

| ما نقوله للمهندس | ما نقوله للعميل |
|---|---|
| Row Level Security على مستوى الصف | «بيانات شركتك في حدودها — لا استعلام يخرج منها، ولو أخطأ البرنامج» |
| صلاحيات على مستوى المستند قبل الاسترجاع | «ما لا يحقّ لموظفك قراءته لا يصل المساعد أصلًا — لا يُخفى بعد ظهوره» |
| التحقق من الكيانات الرقمية مقابل المصدر | «كل مدة ومبلغ في الإجابة نتأكد أنه مكتوب في مستندك فعلًا» |
| ١١٤ اختبار عزل + شاهد سلبي | «نختبر شهريًا أن شركة لا ترى بيانات أخرى — ونعطيك التقرير» |
| لا تدريب على بيانات العملاء | «مستنداتك تُستعمل للإجابة عليك وحدك، ولا تُغذّي أي نموذج» |

> **صفحة الأمان تُقسم قسمين:** أعلاها بلغة العميل، وأسفلها «للفريق التقني»
> بالتفاصيل. من يريد الأولى لا يُرهَق بالثانية، ومن يريد الثانية لا يشكّ في
> الأولى.
